Question: If you create a constructor method to build a DVD by title then create a constructor method to build a DVD by category. Does JAVA allow you to do this?

Answer: Java will throw an error: 'DigitalVideoDisc(String)' is already defined in 'DigitalVideoDisc'.

This is because the overloading method can only be implemented for functions with different signatures (number of parameters and type of parameters). Since both constructors to build a DVD by title and category are 'String' and they only have 1 parameter, Java will be confused and cannot build them in the same class.
